Cloud Tavern Data Upload

How this tool works

  1. This page only touches data/{handle} for the selected SillyTavern user. It never modifies global folders such as _storage.
  2. Always run a simulation upload first to verify structure and safety, then run a real upload.
  3. Before every real upload the system creates an automatic backup, so you can roll back to the state before the last upload.
  4. While a real upload is running, avoid heavy writes on the same account on the main site to reduce conflicts.
